    🔓 Unlock the deep stats — free, 1 minute, step by step

    The live counter above needs no login. But today's exact count, win rate, win streaks, theme strengths and recent attempts are private on Lichess — they need a read-only token from your own account:

    Games, Storm, Streak and Racer need no token and no extra box — they're public and already live above. So when Lichess shows the scope list, tick only puzzle:read: no other box adds anything to this tracker, the rest would only give the token powers it doesn't need (playing moves, sending challenges, messages).

    1. Open lichess.org/account/oauth/token and sign in if asked.
    2. Write any description, e.g. Puzzle Tracker.
    3. Tick only the scope Read puzzle activity (puzzle:read). Nothing else.
    4. Tap Generate, copy the token (starts with lip_) and paste it here. It can only read puzzle activity — it cannot play, chat or change your account, and you can delete it anytime on that same page.

    Enter it once — this browser remembers it. After a successful unlock, the token is saved in this browser on this phone (local storage) and reconnected automatically every time you open this page's website link again — no Muse sign-in, no re-pasting. It is only ever sent to lichess.org, never to any other server, and Disconnect below forgets it instantly. Pasting is cleaned up automatically (stray spaces or line breaks are removed), and Lichess itself confirms the token before anything loads.

    For your dad's phone: send him this page's website link — he opens it in Chrome or Safari (not inside another app), pastes the same token once, and his phone remembers it the same way. Each phone keeps its own saved copy, so he never needs Muse and never has to paste it again. Tip: opening the link inside Facebook/Messenger's built-in browser can forget saved data — open it in the real Chrome/Safari browser for it to stick. If you ever clear that browser's site data, just paste the token once more. You can revoke the token anytime at lichess.org/account/oauth/token.
